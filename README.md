# Aperture Studios

Адаптивный сайт для студии фотографии и видеопродакшена.

## Технологический стек

- **HTML5** (семантическая верстка)
- **CSS3** (Flexbox, Grid, медиа-запросы, плавные переходы)
- **Vanilla JavaScript (ES6+)** (логика работы мобильного бургер-меню)

## Локальный запуск

1. **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com
    ```

2. **Откройте проект:**
   Просто откройте файл `index.html` в любом современном браузере или запустите через расширение **Live Server** в VS Code.
